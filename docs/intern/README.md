# Stajyer Teslim Şablonları

Bu klasör, [intern-roadmap.md](../intern-roadmap.md) programının her haftası için
doldurulabilir teslim formlarını içerir. Stajyer her hafta ilgili formu doldurur,
mentor haftalık 1:1'de gözden geçirir.

## Kullanım
1. Stajyer ilgili haftanın formunu kopyalar/doldurur (kod, çıktı, ekran görüntüsü, özet).
2. Hafta sonu demo öncesi form tamamlanır.
3. Mentor öz değerlendirme + demo checkbox'larını gözden geçirip onaylar.
